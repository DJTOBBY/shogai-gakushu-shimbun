# ネタ帳（生涯学習新聞・取材メモ）

このファイルは、生涯学習新聞の新号を作る際のネタ候補を溜めておく内部メモです。
公開ページ（index.html / backnumbers.html / issues/ / feed.xml / archive.html / sitemap.xml）とは独立していて、
ここに載っている内容がそのまま紙面になるわけではありません。新号を書く人（編集部）が、
ここから使えそうなネタを選んで取材・執筆します。

海外ネタについては、同じ `notes/` フォルダ内の地域別取材メモ（`kaigai-*.md`）も参照してください。

## 記入フォーマット

新しい発見が一番上に来るように追記してください。

```
## YYYY-MM-DD発見
- **[ジャンル]** 見出し（仮）
  - 概要: 1〜2文の要約
  - 出典: [サイト名](URL)
  - 想定面: メモ（任意。例：1面候補／公民館面向き／図書館面向き など）
  - 状態: 未使用
```

ジャンルの例：政策・行政／公民館・社会教育／リカレント・大学／シニアの学び／
図書館／博物館・文化／講座・教室／統計・調査／海外・国際機関／人事・表彰

ネタが実際に号で使われたら、そのエントリの「状態」を `未使用` から
`使用済み（YYYY-MM-DD号）` に書き換えてください。

**曖昧な情報や出典不明の話は載せないこと。** 発表日が確認できない場合は「発表日不明」と明記してください。
